# 4. 不要浪费时间

把事情写具体，按真实耗时安排。方法有没有用，自己试过再调整。

<a id="au-04-01"></a>

### 1. 把“打算做”写成几点、在哪、先做什么

- 成本：几分钟计划。
- 说人话：别只写“我要学习”。写清下一步、时间和地点，把任务缩小到容易开始的程度。可以先试五分钟，开始后再决定是否继续。
- 怎么做：1）写成具体动作，例如下班后坐到书桌前，先填表格第一部分。 2）提前备好材料，设好必要提醒。 3）结束时记下做到哪，给下次留一个起点。
- 收益：少花时间纠结从哪里开始。
- 依据：实践建议；临床自助方法
- 来源：Centre for Clinical Interventions, WA Health：[Practical Techniques to Stop Procrastination — Module 5](https://www.cci.health.wa.gov.au/~/media/CCI/Consumer-Modules/Put-Off-Procrastinating/Putting-Off-Procrastinating---05---Practical-Techniques-to-stop-Procrastination.pdf)（[核实记录](../sources/README.md#l002)）
- 备注：计划可以改。照护、身体状况和临时工作会打乱安排，没做完不等于失败。
- 适用：任务重要却迟迟未开始的人；通用。资料核实：2026-09-16。

<a id="au-04-02"></a>

### 2. 估时间时，看上次实际花了多久

- 成本：记录和回顾的时间。
- 说人话：大项目先拆成能分别推进的小步骤。记几次真实耗时，连沟通、等人和返工也算上，别只算自己动手的时间。
- 怎么做：1）列出做完前必须完成的步骤，以及哪些要等别人。 2）没有外部期限的事，也定个可以调整的检查日期。 3）做完对比预计和实际耗时，下次照着改。
- 收益：安排更贴近实际，早点发现哪里来不及。
- 依据：实践建议；临床自助资料
- 来源：Centre for Clinical Interventions, WA Health：[Practical Techniques to Stop Procrastination — Module 5](https://www.cci.health.wa.gov.au/~/media/CCI/Consumer-Modules/Put-Off-Procrastinating/Putting-Off-Procrastinating---05---Practical-Techniques-to-stop-Procrastination.pdf)（[核实记录](../sources/README.md#l002)）
- 备注：没有人人适用的工期倍数；复杂项目仍要专业估算和风险管理。
- 适用：常低估工期、把大项目拖到最后的人；通用。资料核实：2026-09-16。

<a id="au-04-03"></a>

### 3. 开工前，写下什么情况下继续、什么情况下停

- 成本：写一份短记录，定期回头看。
- 说人话：先写目标、最多愿意再花多少时间或钱、何时回头检查。到时看接下来还要投入多少、能有什么用，再决定是否继续。
- 怎么做：1）写清想要的结果，以及接下来最多肯投入多少时间或钱。 2）到检查日期再看现实条件，分清已经花掉的和接下来可以选择的投入。 3）涉及合同或对别人的承诺，先处理责任，再退出。
- 收益：更容易说清为什么继续、为什么停止。
- 依据：作者实践建议；参考目标与计划方法
- 来源：Centre for Clinical Interventions, WA Health：[Practical Techniques to Stop Procrastination — Module 5](https://www.cci.health.wa.gov.au/~/media/CCI/Consumer-Modules/Put-Off-Procrastinating/Putting-Off-Procrastinating---05---Practical-Techniques-to-stop-Procrastination.pdf)（[核实记录](../sources/README.md#l002)）
- 备注：这是安排和记录的方法，不是收益公式；不能直接套用到投资、治疗或法律义务。
- 适用：正在投入一个可选择的项目、爱好或购买计划的人；通用。资料核实：2026-09-16。

<a id="au-04-04"></a>

### 4. 开会先说清要解决什么，消息也要留时间处理

- 成本：要和团队商量，会前可能多写一些材料。
- 说人话：可以和团队试试：开会前写清目的、资料和要作的决定。能先用文字说清的就提前发，需要当面讨论的再留时间。
- 怎么做：1）先确认谁需要参加，这次要解决什么。 2）非紧急消息约好集中处理的时段，另留紧急联系办法。 3）试一段时间，看有没有漏事或耽误，再调整。
- 收益：少被打断，也让大家知道何时能得到回复。
- 依据：作者实践建议
- 来源：Centre for Clinical Interventions, WA Health：[Practical Techniques to Stop Procrastination — Module 5](https://www.cci.health.wa.gov.au/~/media/CCI/Consumer-Modules/Put-Off-Procrastinating/Putting-Off-Procrastinating---05---Practical-Techniques-to-stop-Procrastination.pdf)（[核实记录](../sources/README.md#l002)）
- 备注：这是一种工作安排建议，没有证明某套开会办法适合所有团队；不能擅自忽略岗位的响应要求。
- 适用：经常被临时会议和消息打断的团队成员；通用。资料核实：2026-09-16。

<a id="au-04-05"></a>

### 5. 刷手机前，先定好什么时候停

- 成本：设置和观察的时间，一般不用买软件。
- 说人话：先看看自己每天花了多少时间，再选想保留的内容。娱乐可以设提醒和结束时间，也要留真正能休息的空档，不必把所有空闲都拿来工作。
- 怎么做：1）先选一个最容易超时的平台，记几天使用情况。 2）需要的信息固定时间看，不必马上知道的就关掉提醒。 3）到点换成提前选好的活动，一周后看看感受和做事情况。
- 收益：少一些刷完才发现时间没了的情况。
- 依据：实践建议；参考行为安排方法
- 来源：Centre for Clinical Interventions, WA Health：[Practical Techniques to Stop Procrastination — Module 5](https://www.cci.health.wa.gov.au/~/media/CCI/Consumer-Modules/Put-Off-Procrastinating/Putting-Off-Procrastinating---05---Practical-Techniques-to-stop-Procrastination.pdf)（[核实记录](../sources/README.md#l002)）
- 备注：这不保证降低疾病风险；控制不住且明显影响生活时，找专业人员帮助。
- 适用：常在无计划浏览中失去时间的人；通用。资料核实：2026-09-16。

<a id="au-04-06"></a>

### 6. 家务要不要花钱请人做，先算一周的账

- 成本：请人要花钱，比较和沟通也要时间。
- 说人话：记一周家务和协调各花了多少时间，再讨论分工和请人。别只拿税前时薪算划不划算，休息时间和照护负担也要算。
- 怎么做：1）记清谁做什么、做多久，谁负责计划和协调。 2）比较服务费、交通、等候、质量，以及省下时间准备做什么。 3）先小范围试一次，家里说好分工和预算。
- 收益：把家务负担说清楚，判断这笔钱值不值得花。
- 依据：作者实践建议；健康关系指南
- 来源：Healthdirect Australia：[Building and maintaining healthy relationships](https://www.healthdirect.gov.au/building-and-maintaining-healthy-relationships)（[核实记录](../sources/README.md#l053)）
- 备注：值不值得取决于预算和省下时间的用途；没钱请人，不必勉强。
- 适用：考虑请清洁、送餐或其他家务服务的家庭；通用。资料核实：2026-09-16。

<a id="au-04-07"></a>

### 7. 选住处时，亲自走一遍通勤路线

- 成本：试乘的钱和看路线的时间。
- 说人话：从家门到目的地走一遍，把走路、等车、换乘和晚上回家都算上。别只看地图距离或列车开了几分钟。
- 怎么做：1）按平时出门的时段试走，看看班次、换乘和无障碍条件。 2）把租金、交通费、每天用时，以及接送和照护一起比较。 3）公共交通按要求用同一张卡或同一个设备进出站，方便核对花费。
- 收益：选房时更清楚每天要花多少钱、多少时间。
- 依据：作者实践建议；交通操作指引
- 来源：Transport for NSW：[Tapping on and tapping off](https://transportnsw.info/tickets-fares/fares/tapping-on-tapping-off)（[核实记录](../sources/README.md#l040)）
- 备注：短通勤不一定就更幸福；路线和票价以当期官方信息为准。
- 适用：准备搬家或改变工作地点的人；Greater Sydney；NSW交通。资料核实：2026-09-16。
