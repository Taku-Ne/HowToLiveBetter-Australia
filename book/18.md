# 18. 养孩子划不划算

政府给的钱、单位能请的假、家里要花的钱和时间，分别算。生不生孩子，最后仍是自己的选择。

<a id="au-18-01"></a>

### 1. 政府育儿补助，先查自己能不能领

- 成本：准备和申请的时间；没批下来前，钱要留余量。
- 说人话：把Services Australia的Parental Leave Pay单独列进预算，按孩子出生或收养日期查规则。是公民或PR，也还要满足工作、收入和居住等条件。
- 怎么做：1）核对自己和伴侣的工作、收入、居住、照护条件，以及等待期和例外。 2）看支付天数怎么分，伴侣是否也要自己申请。 3）按要求登记孩子出生，保存申请和雇主相关记录。
- 收益：别把还不确定的补助当成已经到手的钱。
- 依据：澳洲政府资格指引
- 来源：Services Australia：[Who can get Parental Leave Pay](https://www.servicesaustralia.gov.au/who-can-get-parental-leave-pay)（[核实记录](../sources/README.md#l051)）；Fair Work Ombudsman：[Parental leave](https://www.fairwork.gov.au/language-help/english/holidays-and-taking-time-off-work/parental-leave)（[核实记录](../sources/README.md#l046)）
- 备注：这是政府支付，不会自动增加雇主必须批准的假期，也不是雇主的带薪产假。金额和天数按相关出生日期的官网规则查。
- 适用：准备生育或收养并承担照护的公民、PR及家庭；澳洲。资料核实：2026-09-16。

<a id="au-18-02"></a>

### 2. 育儿假提前谈，工龄、通知和返岗都问清

- 成本：无薪期间收入会少，先做好现金预算。
- 说人话：法定无薪育儿假、单位额外福利和政府支付，分开查。通常满足连续服务要求的雇员可有法定无薪育儿假，部分长期规律工作的casual也可能符合。
- 怎么做：1）先看合同、award或enterprise agreement，再核对Fair Work资格要求。 2）一般至少提前10周书面通知，开始前至少4周确认；做不到时尽快说明。 3）把安全工作、请假和返岗岗位谈清，保存书面确认。
- 收益：请假、照护和收入安排能接得上。
- 依据：Fair Work官方指引
- 来源：Fair Work Ombudsman：[Parental leave](https://www.fairwork.gov.au/language-help/english/holidays-and-taking-time-off-work/parental-leave)（[核实记录](../sources/README.md#l046)）
- 备注：通常需服务满12个月等条件；能申请延长，不等于自动获批。孕期不安全工作及相关假期有专门规则，有争议找Fair Work核实。
- 适用：受相关就业制度覆盖、准备照护新生或收养孩子的雇员；澳洲Fair Work体系。资料核实：2026-09-16。

<a id="au-18-03"></a>

### 3. 托育看最后自己付多少，别只看补贴比例

- 成本：申请时间、托育差额，可能还有交通费。
- 说人话：先查Child Care Subsidy资格，再按机构收费、可补贴时数和实际出勤算自付。补贴通常直接给机构抵扣费用，不是所有费用都报销。
- 怎么做：1）核对居住、照护份额、付费责任和孩子免疫等要求。 2）向候选机构要完整收费、缺勤和取消规则，确认是认可服务。 3）预算留出收费和补贴之间的差额，家庭资料变了及时更新。
- 收益：少因看错补贴或收费规则，临时缺钱。
- 依据：政府托育补助资格指引；预算实践
- 来源：Services Australia：[Who can get Child Care Subsidy](https://www.servicesaustralia.gov.au/who-can-get-child-care-subsidy)（[核实记录](../sources/README.md#l052)）
- 备注：公民或PR也要满足其他条件；不同补助资格不同。别沿用旧activity test来估时数，以Services Australia当期核算为准。
- 适用：需要认可托育服务的家庭；澳洲；悉尼本地服务价格。资料核实：2026-09-16。

<a id="au-18-04"></a>

### 4. 孩子谁带、夜里谁起，先排一周看看

- 成本：沟通时间；可能要少工作或花钱请人。
- 说人话：夜里照护、接送、家务、预约、请假和安抚情绪，各由谁做，先列出来。再谈自己愿不愿意承担这些变化；别让孩子负责满足长辈、挽救关系或将来养老。
- 怎么做：1）分别按普通工作周和孩子生病时的情况排一次班。 2）列出谁能帮、什么条件下能帮，帮不了时怎么办。 3）把决定权、休息时间和职业影响谈清，也允许以后重新讨论。
- 收益：让照护责任看得见，别默认都落在一个人身上。
- 依据：作者实践建议；健康关系指南
- 来源：Healthdirect Australia：[Building and maintaining healthy relationships](https://www.healthdirect.gov.au/building-and-maintaining-healthy-relationships)（[核实记录](../sources/README.md#l053)）
- 备注：这是讨论办法，不是给谁更辛苦打分；尊重和共同分工值得谈，但不能据此断定哪种生育选择更幸福。
- 适用：讨论生育、收养或已有孩子的家庭；通用；澳洲健康关系资源。资料核实：2026-09-16。

<a id="au-18-05"></a>

### 5. 养孩子的预算，分阶段算

- 成本：整理账单和询价的时间。
- 说人话：幼儿、上学和离校后分别估算，分清必需花费、自选花费和可能拿到的补贴。用低、中、高三种情况看看家里撑不撑得住，没有一个总价适合所有悉尼家庭。
- 怎么做：1）先列住房变化、吃饭、用品、托育、接送，以及家长收入变化。 2）托育和育儿支付分别查资格，没批下来的钱别算成确定收入。 3）每年或工作、照护安排改变时重算，留点应急余量。
- 收益：看清哪些支出和收入变化最影响决定。
- 依据：作者预算实践建议
- 来源：Services Australia：[Who can get Parental Leave Pay](https://www.servicesaustralia.gov.au/who-can-get-parental-leave-pay)（[核实记录](../sources/README.md#l051)）；Services Australia：[Who can get Child Care Subsidy](https://www.servicesaustralia.gov.au/who-can-get-child-care-subsidy)（[核实记录](../sources/README.md#l052)）；Healthdirect Australia：[Building and maintaining healthy relationships](https://www.healthdirect.gov.au/building-and-maintaining-healthy-relationships)（[核实记录](../sources/README.md#l053)）
- 备注：这里没列完全部家庭补助，也不用金钱给孩子或父母定价。教育、医疗和其他福利另查对应章节及主管机关。
- 适用：准备养育或已在养育孩子的家庭；澳洲；Greater Sydney。资料核实：2026-09-16。

<a id="au-18-06"></a>

### 6. 因为怀孕被降职或解雇，尽快问清工作保护

- 成本：收集资料和咨询的时间，可先查官方免费信息。
- 说人话：雇主不能因为怀孕就解雇、降职或区别对待。需要避开工作风险时，要按证据和规定安排安全工作，不能直接把怀孕员工换成低薪岗位。
- 怎么做：1）保存原岗位、工资、排班和雇主说明，书面问清变动原因。 2）原工作不适合孕期，提供合理医疗证据、讨论安全岗位；即使育儿假工龄不够，也可能有相关权利。 3）有争议尽快找Fair Work或法律服务，核对投诉和申请期限。
- 收益：分清安全安排和歧视，别误以为自己没资格就放弃求助。
- 依据：Fair Work官方指引
- 来源：Fair Work Ombudsman：[Entitlements while pregnant](https://www.fairwork.gov.au/leave/parental-leave/before-parental-leave/entitlements-while-pregnant)（[核实记录](../sources/README.md#l070)）
- 备注：孕期岗位变化不一定违法；no safe job leave有薪还是无薪要看条件。被解雇等情况别拖着等统一期限，尽快核实。
- 适用：怀孕并受到不利工作安排的雇员；澳洲Fair Work体系。资料核实：2026-09-16。
