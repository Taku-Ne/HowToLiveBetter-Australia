# 高性价比人生指南（澳洲悉尼版）

用尽量少的钱、时间和精力，避开能避开的病、损失和麻烦。

覆盖防病与急救、省钱与理财、失业兜底、租房买房、劳动权益、恋爱婚育、养老、出国和学技能。32 章、267 条建议，每条写明做什么、花掉什么、换回什么，出处跟在结论后面。

主要给能读中文的澳洲公民和永久居民看。办事方法以澳洲、NSW 和悉尼为准。资料最近核实于 2026-09-16，共引用 289 个来源页面。

## 怎么读

- 先看值不值得做：读标题和「说人话」。这里用日常话解释收益和代价；研究里的数字、政策里的期限，放在「收益」中供你核对。
- 再看要付出什么：读「成本」。钱、时间、长期坚持的负担都算成本。能算清楚的写清楚，没有依据的数字不编。
- 准备动手：先读「备注」中的资格和例外，再展开「具体做法」。急救步骤直接展开，免得找的时候多点一次。
- 想自己核对：点「来源」里的原始论文或官方文件。每个来源另附核实记录，写明看了正文还是摘要。
- 想找一个具体问题：从上面的表或下面的目录进入章节，也可以用 GitHub 仓库搜索。
- 刚到悉尼：先看第 32 章，再看租房、看病和工作。其他章节按自己需要读。

每条正文固定六项：**成本、说人话、收益、依据、来源、备注**。具体步骤另列，办事资格留在正文。金额如无特别说明均为澳元；整理账单等操作的用时是编辑粗估，用来比较投入，不是研究结果。

## 哪些地方要看仔细

公民、PR、税务居民、Medicare 和福利资格是几回事。拿到 PR 不代表所有补助马上能领，住在悉尼也不代表能用 City of Sydney 的每一项服务。正文分别标明全国、NSW 和本地条件。

论文结论和办事规则分开看。观察研究发现「有关联」，不能直接说照着做就一定得到同样的好处；政府说某项服务能申请，也不能替你证明自己符合全部条件。条目里的「依据」会说明来源是哪一类。

少生一次病、省下一笔利息、保住申诉期限，是不同的收益，本书分开讲。各章把常见、后果重要、能动手做的事放在前面；这个顺序是编辑判断。结婚、生育和家庭选择，只列代价、条件和可用的帮助，由读者自己决定。

## 目录

1. [不要早死](book/01-不要早死.md)：这里放的是会出大事、而且平时能做点什么的事：交通和居家安全、疫苗、筛查，以及不能拖的身体警讯。没症状时按条件筛查，有症状时直接看病。
2. [不要慢慢死](book/02-不要慢慢死.md)：这节讲每天都要重复的事。能查到研究数字的就写数字；饮食、睡眠和活动按澳洲指南安排，不拿某一种食物或固定步数当长寿保证。
3. [不要浪费精力](book/03-不要浪费精力.md)：精力花在睡不够、反复被打断和做不完的承诺上，留给正事的就少了。本章看怎样调整这些消耗；个人安排不冒充人人有效的研究结论。
4. [不要浪费时间](book/04-不要浪费时间.md)：时间账要算到实际完成：开始前的犹豫、沟通等候、返工、通勤和家务都算。本章给安排方法，不编造人人能省下多少小时。
5. [不要浪费钱](book/05-不要浪费钱.md)：这一章只算钱：停掉什么能少付，买了什么却未必有用，哪些余额现在根本不能动。投资和保险按自己的账比较，不把过去回报当成未来到账的钱。
6. [反面清单](book/06-反面清单.md)：保健品、体检套餐和附加功能，便宜不等于值得长期买。这里区分“没有必要人人买”和“所有用途都无效”，有明确治疗需要的另算。
7. [没钱的时候怎么活](book/07-没钱的时候怎么活.md)：先解决今晚吃住和必要治疗，再查能领的补助、优惠和免费支持。每项都看自己的资格和首笔到账时间，不能拿一句「有 PR」代替完整预算。
8. [别把自己搭进去](book/08-别把自己搭进去.md)：事故、诈骗和争议已经发生，先把人和后续损失保住，再留证据、找对程序。担保、董事这些看着只是签个名的事，最坏要用自己的钱和责任来还。
9. [普通人容易踩的法律红线](book/09-普通人容易踩的法律红线.md)：有些事错在把「别人也这样做」当成许可：同意、录音、收转钱、无人机和像枪的玩具，都有自己的规则。这里按 NSW 及标明的全国要求讲清，做之前先看条件。
10. [恋爱和结婚划不划算](book/10-恋爱和结婚划不划算.md)：恋爱看相处，结婚和分开还要算财产、债务、家务和时间。感情里的承诺与法律上的权利，不能当成同一件事。
11. [程序员和技术人容易踩的红线](book/11-程序员和技术人容易踩的红线.md)：接活不只看能不能做出来，还要看有没有权做、成果归谁、出了问题谁负责。授权、许可证和合同在开工前查，省的是交付后改写、扯皮和赔偿的代价。
12. [创业与做生意](book/12-创业与做生意.md)：先算启动要花多少、每月还要付多少、最坏能亏多少，再签长期合同。注册、税务、雇人、产品和退出各有责任，销售额不能直接当成自己赚到的钱。
13. [紧急情况](book/13-紧急情况.md)：急救先看危险、意识和呼吸；危及生命打 000。下面写的是当下该做什么、哪些动作会添乱，具体手法仍要接受实际训练并听接线指导。
14. [账号与信息安全](book/14-账号与信息安全.md)：邮箱能找回其他账号，手机能收验证码和付款：一处失守可能牵连多处。保护设置提前做，丢失或异常交易发生后尽快止损。
15. [租房与买房](book/15-租房与买房.md)：租房争议靠合同、状况报告和付款记录说话；买房的退出条件要在签字前看。本章按NSW一般住宅规则，寄宿、学生宿舍等特殊住宿可能不同。
16. [得了慢性病之后怎么活](book/16-得了慢性病之后怎么活.md)：慢性病的花费不只在药上，还在反复复诊、检查和取药。把该查的排好、所有药列清，能用的补助和长处方问清楚，别靠感觉停药。
17. [家里有老人](book/17-家里有老人.md)：生活医疗由谁决定、钱由谁管理、遗产怎么分，需要不同文件。现在把权限和意愿写清，才不用将来靠亲属身份和口头记忆猜。
18. [养孩子划不划算](book/18-养孩子划不划算.md)：育儿要分开算政府支付、雇主给的假、托育自付和家长少挣的钱。补助能抵一部分支出，不能替你决定愿不愿意承担照护。
19. [在职、离职和工伤](book/19-在职离职和工伤.md)：这一章讲工资怎么核、离职怎么结、解雇和工伤什么时候办。NSW 工伤在 2026 年改过规则，首次通知日、评估次数和过渡期都可能影响权益。
20. [刚出生的孩子怎么带](book/20-刚出生的孩子怎么带.md)：新生儿用品可以少买，睡眠、喂养、接种和生病后的处理不能凭感觉。这里先讲做错可能出事的几件事。
21. [出国旅行与境外安全](book/21-出国旅行与境外安全.md)：出发地在澳洲，不代表拿的是澳洲护照。签证、PR返澳权限、领事服务和保险分别看，不能用其中一项代替其他项。
22. [怎么放松](book/22-怎么放松.md)：外出先留好离开的路和回家的办法，消费先看收费；放松则找愿意重复、负担得起的活动。安全、花钱和缓解压力，分别判断。
23. [学什么技能划算](book/23-学什么技能划算.md)：学费只是成本的一部分，少赚的工资、实习和拿证后的入行门槛也要算。先看本地岗位要什么，再查课程能补什么；补贴、学额和贷款分别核对。
24. [看病](book/24-看病.md)：在澳洲看病，挂上号、拿到转介、有 Medicare 卡，分别不等于马上能看、看完免费。先弄清入口和自付，急症则直接求救。
25. [人走了以后要办什么](book/25-人走了以后要办什么.md)：先分清眼前是否仍需急救，再处理登记、葬礼和遗产。每件事的办理人、证明和权限不同，亲属关系不能代替全部手续。
26. [做一个网站或平台](book/26-做一个网站或平台.md)：做平台，开发费只是开头。业务许可、钱的去向、用户资料、内容投诉和故障恢复，都要有人负责；上线前把这些事和持续开销算清。
27. [怀孕和生产](book/27-怀孕和生产.md)：孕期有些事过了时间再补就不一样，有些症状不能等下次产检。这节把常规安排、需要马上求助的情况，以及分娩和产后的选择分清。
28. [别为了外形把身体搞坏](book/28-别为了外形把身体搞坏.md)：外形带来的困扰是真的，治疗和手术的代价也是真的。先查有没有适应证、谁来做、后续谁管，别把长期身体风险当成变好看的附带小事。
29. [遭遇重大打击之后](book/29-遭遇重大打击之后.md)：重大打击会打乱吃饭、睡觉、治疗和办事能力。先守住基本生活；困难已经影响生活，就按眼前的需要找帮助，不用等一个规定的悲伤期限。
30. [上学以后的孩子](book/30-上学以后的孩子.md)：孩子还在上学，不等于看病都能挪到假期。急症及时处理，慢性问题让学校一起安排；视力、牙齿、睡眠和心理困难各有需要管的地方。
31. [十八岁之后有哪几条路](book/31-十八岁之后有哪几条路.md)：十八岁之后，大学和直接打工之外还有职训、学徒、军职和公职。先看能不能进，再算读多久、花多少钱、要接受什么承诺。公民和 PR 的条件不完全相同。
32. [悉尼日常办事](book/32-悉尼日常办事.md)：账户、交通和公共服务，常见差错是入口找错、资格看错或地址范围用错。先弄清自己适用哪一套，再花钱或提交申请。

## 从哪里改来的
