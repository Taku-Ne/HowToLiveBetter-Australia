# 高性价比人生指南（澳洲悉尼版）

在悉尼生活，哪些事值得做，哪些坑可以绕开。

覆盖防病与急救、省钱与理财、失业兜底、租房买房、劳动权益、恋爱婚育、养老、出国和学技能。32 章、267 条建议，每条写清花什么、换什么、怎么做、根据什么。

主要给能读中文的澳洲公民和永久居民看。办事方法以澳洲、NSW 和悉尼为准。资料最近核实于 2026-09-16，共引用 289 个来源页面。

## 怎么读

- 只想先知道该干什么：看条目标题和「说人话」。准备照着做时，把「怎么做」「备注」「适用」一起读。
- 想算值不值：看「成本」和「收益」。能省多少钱、能降低多少风险，有可靠数字就写数字，没有就不硬编。
- 想自己核对：点「来源」里的原始论文或官方文件。每个来源另附核实记录，写明看了正文还是摘要。
- 想找一个具体问题：从上面的表或下面的目录进入章节，也可以用 GitHub 仓库搜索。
- 刚到悉尼：先看第 32 章，再看租房、看病和工作。其他章节按自己需要读。

每条采用「成本—说人话—怎么做—收益—依据—来源—备注」的写法。办事资格单独列在末尾，金额如无特别说明均为澳元。

## 哪些地方要看仔细

公民、PR、税务居民、Medicare 和福利资格是几回事。拿到 PR 不代表所有补助马上能领，住在悉尼也不代表能用 City of Sydney 的每一项服务。正文分别标明全国、NSW 和本地条件。

论文结论和办事规则分开看。观察研究发现「有关联」，不能直接说照着做就一定得到同样的好处；政府说某项服务能申请，也不能替你证明自己符合全部条件。条目里的「依据」会说明来源是哪一类。

本书保留原项目关心的健康、时间、精力、金钱和权益。各章把常见、后果重要、能动手做的事放在前面。不同收益不硬换算成一个分数，结婚、生育和家庭选择由读者自己决定。

## 目录

1. [不要早死](book/01.md)：先做能少出大事的事：系安全带、防火、打该打的疫苗、做适合自己的筛查。有症状就看病，别等下次筛查。
2. [不要慢慢死](book/02.md)：吃饭、运动、睡觉、刷牙，这些每天重复的小事值得做好。挑能坚持的做法，不必追一种食物或一个步数。
3. [不要浪费精力](book/03.md)：先睡够，再减少打断、安排分工。精力不够用时，也要给休息和求助留时间。
4. [不要浪费时间](book/04.md)：把事情写具体，按真实耗时安排。方法有没有用，自己试过再调整。
5. [不要浪费钱](book/05.md)：先把用不上的订阅、重复的保险和不必要的费用停掉，再考虑投资。涉及投资的条目只讲怎么比较，不保证收益。
6. [反面清单](book/06.md)：有些健康产品卖得好，未必对你有用。先问能解决什么问题、证据是什么，再掏钱。
7. [没钱的时候怎么活](book/07.md)：先保住安全、住处、食物和必要医疗，再找现金补助、工作和法律帮助。每项支持都有自己的条件，能申请一种不代表其他种也自动有。
8. [别把自己搭进去](book/08.md)：出了事故、被骗或卷入争议，先保护人、止住损失、留下证据，再找对处理机构。索赔期限和能拿到的赔偿，要看具体事情。
9. [普通人容易踩的法律红线](book/09.md)：这里讲 NSW 日常生活中容易弄错的规则。涉及全国规则或其他地区时，另行标明。
10. [恋爱和结婚划不划算](book/10.md)：相处好不好，钱和家务怎么分，结婚或分开有什么法律后果，分开想清楚。
11. [程序员和技术人容易踩的红线](book/11.md)：开工前先确认谁能授权、允许你做什么，代码和数据最后归谁。能做到，不代表有权做。
12. [创业与做生意](book/12.md)：先算能亏多少，再开张。注册、税务、行业许可、雇人和产品安全要分别办；没摸清需求前，别急着背长期租约、囤货或替公司担保。
13. [紧急情况](book/13.md)：先保自己安全，再救人。危及生命时打 000，照接线员指导做；文字不能代替实际急救训练。
14. [账号与信息安全](book/14.md)：先保住邮箱和手机。出了事尽快止损，别等找回设备才保护账号和钱。
15. [租房与买房](book/15.md)：租房留好合同、照片和押金记录，买房先让自己的专业人员看合同。本章按NSW规则，寄宿、学生宿舍等特殊住宿可能不同。
16. [得了慢性病之后怎么活](book/16.md)：药别乱停，复诊别靠记性，费用提前问。把长期治疗安排成日子里做得下去的事。
17. [家里有老人](book/17.md)：医疗、生活和财务分别安排。趁老人能自己作决定时先谈清楚，别为了省事就替他接管一切。
18. [养孩子划不划算](book/18.md)：政府给的钱、单位能请的假、家里要花的钱和时间，分别算。生不生孩子，最后仍是自己的选择。
19. [在职、离职和工伤](book/19.md)：先把工资、工时和雇佣身份查清，离职时逐项算账。NSW 工伤规则在 2026 年有变化，旧经验要重新核对。
20. [刚出生的孩子怎么带](book/20.md)：先管好睡觉、喂奶、接种和生病时求助。东西不必买贵，安全要求要照做。
21. [出国旅行与境外安全](book/21.md)：先看自己拿什么护照、是什么身份。公民、PR和双重国籍者，入境、返澳和领事帮助的规则不同。
22. [怎么放松](book/22.md)：找便宜、愿意重复的小活动。能帮自己缓一缓就有用，不必追求统一方法，也别拿放松代替必要治疗。
23. [学什么技能划算](book/23.md)：先看学完能做什么工作，再算学费、实习和少赚的工资。学历、职训、学徒和短课各有用处，别只看宣传里的最高薪酬。
24. [看病](book/24.md)：平时找 GP，急症打 000。Medicare 能报多少、自己要付多少，预约时分开问清楚。
25. [人走了以后要办什么](book/25.md)：先处理眼前的事，再分工办葬礼、登记和遗产。难过时可以请亲友和专业人员帮忙，办事的人也要弄清自己的权限。
26. [做一个网站或平台](book/26.md)：先弄清网站做什么、钱经过谁的账户、谁能看到用户资料，再动手开发。免费服务或海外服务器都不是免除责任的理由。
27. [怀孕和生产](book/27.md)：尽早找好产科团队，弄清检查、疫苗和紧急求助办法。生完以后，也别漏掉自己和孩子的后续安排。
28. [别为了外形把身体搞坏](book/28.md)：想好看没有问题。药从哪来、谁给你做、出了问题怎么办，这些要在付款前问清楚。
29. [遭遇重大打击之后](book/29.md)：先让自己吃得上饭、睡得了觉，有需要时找人帮忙。难过没有统一期限，也不用等够几个月才求助。
30. [上学以后的孩子](book/30.md)：身体和情绪出了问题，别都让位给上课考试。需要治疗或支持时，让医生和学校一起想办法。
31. [十八岁之后有哪几条路](book/31.md)：大学、职训、学徒、军职和公职都可以逐项比较。公民和 PR 的资格不完全一样，先看自己能不能申请，再算时间、钱和服务承诺。
32. [悉尼日常办事](book/32.md)：政府账号、选民登记、交通、驾照、能源、垃圾和图书馆，先找对入口，再查自己能不能用。

## 从哪里改来的

本书参考 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) 的选题、章节和写法。原书 498 条建议的处理都记在[改编对照](docs/ADAPTATION.md)里。

适用的科学研究可以引用同一篇原始论文；中国特有的办事方法，换成核实过的澳洲做法。出处直接跟在建议后面，原作者贡献和固定版本见[参考说明](ATTRIBUTION.md)。
