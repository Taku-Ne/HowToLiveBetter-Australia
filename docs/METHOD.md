# 怎样写、怎样核实、怎样更新

[← 总目录](../README.md)

面向能读中文的澳洲公民与永久居民，按澳洲、NSW、悉尼分别写明办事范围。移民身份、税务居民、Medicare 资格和福利等待期不能互相替代。

## 原书怎么用

固定基线是 eternity4719/HowToLiveBetter 的提交 `a6f000dc94af0a9bcd28405fcdf25c8370c4cb36`。正文保留 31 章、498 条及原顺序、原章节文件名；不合并、不删题、不用别的问题顶替。原题涉及中国独有制度时，在原位置回答澳洲有没有对应安排、应怎样处理。

通用研究可以保留相同论文、研究人群、效应量、置信区间和争议。引用原书本身也可以，但必须说明转引；不能把原仓库的核查自动算成本项目读过原文。原书中发现的统计误读、过度推论或不适用于澳洲的做法，要修正后再写。

`reuse` 表示保留研究或一般原理，`adapt` 表示需要替换澳洲制度或实际做法；同一条可能同时保留研究和改写本地方法。逐条理由见[改编对照](ADAPTATION.md)。悉尼额外九条生活入口放在附录，不改变正文编号。

## 来源记录怎么读

| 标记 | 实际含义 |
|---|---|
| full_page | 读取了该页面支持相关说法的正文，不表示逐一打开页面全部外链 |
| abstract | 读取原论文摘要或作者摘要，不表示读到全文、附录和全部方法 |
| pdf | 读取了 PDF 中相关正文，不表示所有章节均逐字审阅 |
| upstream_citation | 读取原书对应条目并保留其书目；尚未据此独立通读原论文 |

O 开头的 498 项记录固定到原书的 498 个条目。它们是选题及转引出处，不能单独证明澳洲法律、药物用法或福利资格。论文书目留在正文中，新增的澳洲或独立读取来源另外列出，读者可以分辨。

来源记录包含发布方、URL、访问日期、读取范围和所支持的具体内容。搜索结果只用来找线索，不标成读过正文。重复 URL 可能支持不同问题，因此来源记录数不等于独立文献数；原书书目中的多个文献也不逐篇算成已独立核读。

## 澳洲事实怎么查

法律、费用、申请资格优先查现行法规和主管机关具体页面。区分发布日期、生效日期、过渡安排、联邦与 NSW 规则。政府导航页只能支持入口，不足以单独支持一个复杂的法定结论。

医疗和急救优先查澳洲指南、主管机构及原始研究。观察性关联不写成因果；OR、HR、RR、IRR 不混用；相对降幅不能改成绝对概率。国外试验可有通用价值，但地区、年龄、疾病和基线风险要保留。正文中的研究数字不能相加得出个人延寿总数。

实践建议明确为编辑建议，不伪造证明其效果的试验。无法确认的精确数字不充当澳洲事实；可以保留为有日期、地区及限制的原书转引，或解释不适用的原因。

## 怎么写

正文固定六栏：**成本、说人话、收益、证据等级、来源、备注**。用短句说具体动作与得失；研究细节留在收益，资格、反例、争议留在备注。步骤直接可读，尤其不能把救命动作藏在展开按钮里。

原版章节和位置用来对照，不代表已经证明同样的性价比排序适合澳洲。A／B／C 是沿用的阅读提示，「规则」用于办理制度；它们不是 GRADE，也不表示来源都已全文核实。

## 怎么检查和更新

编辑 `sources/guide.json`，运行构建及验证。自动检查必须拦截：缺章、少题、多题、调序、合并、错位映射、缺引用、虚构来源编号、原书转引误标全文、坏内部链接、缺少六栏和错误文件名。

自动检查只验证结构。内容还要回到来源，核对数字、条件和实际含义；交叉复读不能称为专业全面审校。对医疗、法律、财务的重要变动，尽可能请相应专业人士复核。

跨财年的税、福利、收费，以及紧急求助与申请期限要优先复查。改动留下来源和日期；尚未设置自动定时更新，不把 HTTP 200 当作事实一直有效。
