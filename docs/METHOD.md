# 怎样写、怎样核实、怎样更新

[← 总目录](../README.md)

本书面向能读中文的澳洲公民和永久居民，以澳洲全国规则为基础，优先解释 NSW 与 Greater Sydney 的实际路径。身份只是一项条件，不替代年龄、收入、资产、居住时间、健康状况或具体项目资格判断。

## 依据的优先顺序

1. 法律政策：现行法规、主管机关的具体实施页面。留意公布日期、生效日期、过渡安排，以及 federal/NSW/local 的管辖区别。
2. 健康急救：澳洲主管机构或专业指南；研究结论再查原始论文、系统综述和摘要。观察性相关不写成因果，也不把特定试验人群的相对风险当成普通居民的绝对收益。
3. 服务和资格：服务提供方的正式办理页面、主管机关的查询或计算工具。新闻、论坛、搜索摘要仅作线索，不作为已核实的唯一依据。
4. 实践建议：明确写为整理方法或操作建议，附相关依据，不伪造证明其效果的研究。

官方资料可以准确解释自己的服务，但不表示它能支持本书额外作出的推论。每条出处必须支持实际写下的内容，而不是只与主题有关。

## 来源记录的含义

每个来源记录包括标题、发布方、具体 URL、访问日期、实际读取范围，以及支持内容的释义。只读取摘要的论文标为摘要；只看到标题或导航页的不列为完整核实来源。原仓库的核实记录不自动成为本项目的核实记录。

研究作者逐条阅读来源，整合阶段复核重点高风险内容并抽查其他内容；这仍不等于独立医生、律师或持牌财务专业人士逐条审校。自动检查只能发现漏引、失效的内部引用、遗漏映射和格式问题，不能证明建议正确。

## 写作与排序

每条说明谁适用、在哪里适用、怎么操作、要付出什么、可能得到什么，以及限制。用具体英文机构名帮助中文读者办事。没有可靠数字时写收益方向和边界；不编造一个“高性价比分数”。

各章优先安排常见、后果重要、能够采取行动的事项，这是编辑判断。关于伴侣、家庭、育儿和陌生人互助，不把作者的价值取向包装成研究结论，也不替读者决定是否结婚、生育或承担责任。

## 原书如何使用

固定原始提交并保留全部 498 条的目录记录。每条标明沿用原理、澳洲改写、合并或不采用，并给出具体理由和新版目标。合并的作用是减少重复；不能用“已合并”掩盖一个仍需解释的主题。中国特有制度若不适用，要明确记录，而非用机构名替换制造等价关系。

原文中未充分核实的细节、量化收益和一刀切判断不自动继承。国际研究即使仍适用，实践步骤、费用、资格和本地风险也要重新核对。所有引用都以该条的具体事实为准。

## 维护节奏

- 法律、资格、工资、税务和服务变化：接到变更信息时优先重查，不等到固定周期。
- 每个季度人工复核医疗、福利、税务、租赁、劳动权利和紧急求助入口。
- 每年整体重读指南；跨财政年度的费用与资格必须特别核对。
- 修订时记录原说法、新说法、依据和核实日期；重要修正写入 CHANGELOG。

本仓库尚未设置定时自动更新。未来可自动发现坏链接或提醒到期复核，但内容变化需要人工判断；不能把 HTTP 200 当作事实仍然有效。
