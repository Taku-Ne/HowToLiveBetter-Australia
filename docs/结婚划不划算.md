# 结婚划不划算：把一笔糊涂账拆成五笔清楚账

结婚到底是亏还是赚，对方能不能分担家务、能不能赚钱、能不能提供情绪价值，还是只为长辈交差？这些问题不能用一个总分回答。每月少付一点房租，不能直接抵掉每天多做的家务；已婚人群的死亡率较低，也不能证明眼前这段关系值得继续。

下面按原来的五笔账分别算。统计用澳洲数据，法律以在NSW生活的澳洲公民和PR为主要场景；跨地区研究保留样本和限制。资料核对至2026年9月16日。没有可靠统一数字的项目，留给你按实际情况填。

## 一、先把问题拆开

1. **钱**：婚礼、住房、日常支出、负债和退休金，按实际金额算；收入和资产不混算。
2. **时间**：做饭、清洁、接送、照护、安排一家人的事情，按每天或每周小时算。
3. **健康**：婚姻状态与死亡率的研究，给的是群体相对风险，不能换算成你能多活几年。
4. **法律风险**：资产债务怎么处理、退出要多久、谁有权申请，按适用规则看。
5. **关系质量**：支持、尊重、信任和冲突，靠长期相处观察；研究效应量不能当作个人评分表。

这五笔账分开写。哪一笔更重要，由当事人决定，不能拿一种口径的“赚”自动抵另一种口径的“亏”。

## 二、每笔账的数据与来源

### 登记数据：结婚率和离婚率是两种粗率

ABS记录，2024年澳洲登记结婚120,844对、获准离婚47,216对；粗结婚率和粗离婚率分别为每千名**16岁及以上人口**5.5和2.1。它们回答的是这一年有多少登记或判决，不是一对新人最终离婚的概率。[ABS：2024年婚姻与离婚统计](https://www.abs.gov.au/statistics/people/people-and-communities/marriages-and-divorces-australia/2024)

把47,216除以120,844，得到约39.1%，只是把同年两种不同事件放在一起。今年离婚的人，大多不是今年结婚的人；这不能读成“澳洲约四成婚姻最终离婚”。同样，这份登记统计也不能代表所有事实伴侣关系的开始和结束。

### 健康账：已婚者死亡率较低，但这是相关，不是因果

原书引用的三项荟萃分析仍有参考价值：

- **Manzoli等（2007）**：53组比较、25万余名老年人，已婚相对非婚的全因死亡相对风险RR为0.88（95%置信区间0.85–0.91），最保守重算为0.94。丧偶、离异或分居、从未结婚相对已婚的RR分别为1.11、1.16、1.11。研究发现发表偏倚迹象。[研究摘要](https://pubmed.ncbi.nlm.nih.gov/17011690/)
- **Roelfs等（2011）**：95篇文献、5亿余人的资料，较高质量、多变量调整的合并结果中，从未结婚相对已婚的全因死亡HR为1.24（1.19–1.30）；关联随年龄增大而减弱。HR是随访期间死亡发生速率的相对指标，不是“每100人多死24人”。[研究摘要](https://pubmed.ncbi.nlm.nih.gov/21715646/)
- **Wang等（2020）**：21项研究、约789万人，非婚状态与全因、癌症及心血管死亡有相关，部分关联在男性中更强。论文用31%和9%概括从未婚相关卒中和全因死亡关联的性别差别；其计算比较的是女性和男性各自“从未婚相对已婚”的RR，不能读成未婚男性绝对死亡概率比未婚女性高31%或9%。论文标题与摘要的总人数略有出入，因此这里只取约数。[研究全文](https://doi.org/10.1186/s41256-020-00133-8)

这些研究没有把人随机分去结婚或不结婚。健康、收入、社会支持既可能影响结婚，也可能影响寿命；有些研究还未充分区分稳定同居、丧偶和婚姻质量。欧美等地区的历史样本可以帮助理解量级，不能直接预测今天悉尼某个人的结果。

所以，RR为0.88不能翻译成“结婚这项操作让你少死12%”。更贴近自己的问题是：这段关系会让睡眠、饮食、运动、就医和求助变得更容易，还是更难？

### 时间账：无酬劳动的平均差距，不是你的上限

ABS的2024年时间利用调查覆盖15岁及以上人群。在**参与无酬活动的人**中，男性每天平均3小时52分，女性4小时53分，相差1小时1分；参与率分别为81%和90%。有15岁以下孩子的参与者中，女性平均7小时29分、男性5小时2分。[ABS：澳洲人怎样使用时间](https://www.abs.gov.au/statistics/people/people-and-communities/how-australians-use-their-time/latest-release)

这里的无酬活动不只包括洗碗扫地，也包括照护等活动；参与者平均与全体人口平均不是同一个数。这些分组没有证明结婚让每位女性每天多做1小时1分，也没有证明生孩子会让某个人增加固定工时。平均差距更不是个人可能承担家务的“上限”。

对你有用的做法，是把自己的一周写下来：谁做饭，谁采购，谁记得预约和接送，孩子生病谁请假，老人需要帮助谁出面。不要只分“做”的工作，也分清谁负责发现、安排和跟进。没有孩子时谈一次，有孩子或照护老人后再谈一次。

### 钱账：默认规则、正式约定和家务贡献

婚礼和住房没有适合所有悉尼家庭的统一价格。用实际报价和自己的收入、负债算，比套一条“平均结婚成本”更实在。

澳洲家庭法下，关系结束后的财产处理也没有固定对半分公式。需要看资产和债务、双方财务及非财务贡献、家务和照护贡献，以及现在和未来的情况；适用情况下还要考虑家庭暴力的经济影响。婚前财产、单独名下的财产、继承或家庭赠与，不会仅凭名称就自动排除在考虑之外。[家庭法院：财务和财产](https://www.fcfcoa.gov.au/fl/fp/overview)

没登记结婚，也不等于没有财务权利义务。NSW的事实伴侣（de facto）申请联邦家庭法财务命令，通常须满足累计关系至少2年，或有关系中的孩子、关系已按规定注册、或有重大贡献且不作命令会造成严重不公等门槛，并满足地域等条件。不是所有室友或短期交往都算，也不是只要住满两年就必定分一半。[家庭法院：事实伴侣关系](https://www.fcfcoa.gov.au/fl/pubs/defacto)

想事先约定，应问清financial agreement的要求。具有约束力的财务协议通常需要双方各自取得独立法律意见，并满足其他法定条件，仍可能被法院撤销；网上模板或两人签字的纸条不自动等于有效BFA。[家庭法院：财务协议](https://www.fcfcoa.gov.au/fl/fp/financial-agreements)

父母出资，转账时就写清借给谁、送给谁、是否还款；真正的借款还要有相应履行记录。书面记录帮助证明真实安排，但不是保证某项资产永不受家庭法影响的办法。

债务还要分两层看：双方最终怎样分担，和贷款人按合同能向谁追偿。分手协议写“由对方还”，不一定解除共同借款或担保责任。把个人贷款、共同贷款、家庭借款、担保一起列出来，办好有效变更并取得贷款人的书面确认，才知道谁仍负有责任。[Attorney-General’s Department：分手后的债务指南](https://www.ag.gov.au/sites/default/files/2025-06/english-family-law-debt-guide-may-2025.PDF)

### 退出成本：离婚、财产和孩子是几件事

澳洲实行无过错离婚。通常须分居至少12个月，证明婚姻已无法挽回；不要求先证明对方出轨或有其他过错。可以同住一个屋檐下分居，但需要额外证据。澳洲法院还要有管辖权，例如任一方是澳洲公民、以澳洲为家并打算长期居住，或在申请前通常居住满12个月。

离婚令通常在作出后1个月零1天生效。离婚本身不处理财产分割，也不替双方解决孩子的全部安排；有未满18岁孩子时，法院需考虑相关安排。[家庭法院：离婚](https://www.fcfcoa.gov.au/fl/divorce/divorce-overview)

婚姻财务申请一般须在离婚生效后12个月内提出，事实伴侣一般须在分手后2年内提出。逾期通常需要法院许可，不保证获准；不必等离婚生效才开始谈财产。律师费、申请费、搬家、两处住房和照护调整，都应按自己的实际情况估算。[财产申请与时限](https://www.fcfcoa.gov.au/fl/fp/overview)

如果有暴力、威胁或控制，安全保护不用等分居满12个月。紧急危险拨000；在NSW，亲密伴侣之间符合要件的强制控制自2024年7月起构成刑事犯罪，具体适用要看行为和法律条件。[NSW：强制控制与法律](https://www.nsw.gov.au/family-and-relationships/coercive-control/law)

### 关系质量：比“有没有结婚”更接近你要算的一笔

Robles等（2014）汇总126篇研究、7.2万余人：婚姻质量与健康的关联效应量r为0.07–0.21，死亡结局r为0.11，冲突时心血管反应r为−0.13。这些是不同指标的小幅关联；部分结局有发表偏倚，多数设计不能推断因果。不能把它们加在一起，也不能直接换成某个人的健康收益。[研究摘要](https://pubmed.ncbi.nlm.nih.gov/23527470/)

Dhindsa等（2020）的心血管综述也讨论婚姻状态、婚姻质量与心血管结局，但这不能给出“低质量婚姻比不婚差多少”的可靠统一数字。该文在这里保留原书转引，本版未独立核读其全文。[论文信息](https://doi.org/10.1016/j.tcm.2019.05.012)

实际可以观察的是：意见不同的时候，能否谈清楚；一方生病、失业或疲惫时，另一方做了什么；分工失衡后，是否愿意调整。只有甜言蜜语，没有行动，和有行动但不善表达，也不是同一回事。这是观察关系的方法，不是经过验证的打分量表。

## 三、怎么给自己算：一张填空清单

不同口径不相加。填不出来就写“不知道”，再看这个未知是否重要到需要先弄清。

**对方能提供什么**

- 钱：稳定到手收入多少？负债和担保多少？资产、super和手头可用的钱各是多少？
- 时间：现在谁做哪些家务？谁负责安排？有孩子、失业、生病或照护老人时，准备怎样改？
- 关系质量：过去半年发生过什么冲突，怎样结束？承诺落实了多少？双方能不能自由说“不”？
- 情绪支持：与对方相处后，通常更有精力，还是长期疲惫？对方需要支持时，自己又怎样回应？

**自己要付出什么**

- 钱：婚礼、搬家和住房要花多少？父母出的钱是赠与、借款还是担保？如果不这样花，原本准备做什么？
- 时间：预计每天做多少无酬劳动？谁会减少有薪工作？职业和退休储蓄的影响是否谈过？
- 健康：作息、饮食、运动、就医和求助会有什么变化？别用群体RR代替自己的生活记录。
- 退出成本：短期独立住房、交通和必要照护能否安排？法律帮助从哪里找？知道适用时限吗？

**法律上怎么保护双方**

- 列清资产、债务、super、家庭出资和担保，保留合同、流水、赠与或借款资料。
- 若考虑财务协议，双方分别取得独立法律意见；弄清覆盖范围、条件和可能失效的情形。
- 家务和照护贡献也要谈，不只比较工资。协商中的承诺怎样落实，重大变化时是否重谈？
- 共同贷款或担保的合同责任是什么？分手时怎样解除？不要只凭伴侣口头承诺。
- 不登记结婚是否仍构成de facto，是否达到财务申请门槛？有具体疑问时带事实问律师。

**为长辈结婚这一栏，单独填**

- 长辈希望得到什么：安心、面子、有人养老，还是别的？
- 这些收益哪些是长辈的，哪些也是自己的？
- 长辈是否提供真实资金、住房或照护支持？附带什么条件，能持续多久？
- 自己和伴侣要承担哪些长期成本，是否都愿意？

亲属的支持和期望都可以算进去，但不能因为长辈高兴，就假定这段关系的其他四笔账也会变好。

## 四、常见误区

**把离结比当最终离婚概率。** 2024年约39.1%的同年离婚数／结婚数，比的是两批人；粗离婚率2.1‰又是另一种口径。都不能直接回答你们以后会不会离婚。

**把相关当因果。** 已婚与较低死亡率相关，不等于取得结婚证就能得到相应保护。稳定同居、社会支持和婚姻质量也不能忽略。

**把结婚当任务。** 完成的是身份变化，不是自动得到分工、支持和信任。需要观察和商量的事情，登记之后仍然存在。

**把平均数当自己的数。** 全国男女无酬劳动平均差距既不是你的必然结果，也不是上限；用它提醒双方谈分工，再用自己的时间表算。

**把不结婚当没有法律关系。** NSW符合条件的de facto关系也可能有财务申请；反过来，结婚也不等于财产自动一人一半。

**把一张纸当万能保护。** 财务协议、财产命令、贷款合同和父母借款是不同文件，约束的人也不同。双方内部说好，不一定约束银行或法院。

**没有合适数字时，硬补一个总价。** 本文没有采用统一的悉尼结婚、养娃或离婚总成本。用你的报价、账单和时间记录；不知道的部分留空，别让精确的假数字替你作决定。
